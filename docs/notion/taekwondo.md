<callout icon="🥋" color="gray_bg">
**묵직한 한 방의 발차기**\
한 방 한 방이 무거운 발차기. 앞차기 → 돌려차기 → 뒤후려차기, 나래차기로 띄운 뒤 공중 추격.
</callout>

## 개요

- 발차기 리치 +15~20cm
- 묵직한 타격 (경직·흔들림 ×1.35)
- 특수키: 540 회전차기
- 대시 + 발: 이단 옆차기

<callout icon="📌" color="blue_bg">
대표 연계\
- 최대 피해 지상 연계: **C C X** (앞차기 → 돌려차기 → 뒤돌려차기) — 3타 207

## 5. 띄운 후 추가 연계

띄운 상대는 낮게 떠서 천천히 떨어진다. 띄우기가 맞으면 **X로 후딜레이를 끊고 서서 주먹을 넣고**, 연계 창이 닫힌 뒤 다시 X를 누르면 첫 주먹이 다시 나간다(**끊치**). 기본 루트는 **띄우기 → 끊치 2회 → 지상 콤보**. 점프(Space)로 쫓아가 공중에서 칠 수도 있다. 공중 추가타는 맞을수록 덜 뜨므로(저글 감쇠) 무한 연계는 되지 않는다.

| 띄우기 연계 | 추가 입력 | 추가 타수 | 총 타수 | 총 피해 |
|---|---|---|---|---|
| C X (앞차기 → 나래차기 (띄우기)) | X → X(끊치) → X(끊치) → X → C | +5 | 8 | 276 |
| C X (앞차기 → 나래차기 (띄우기)) | X → X → C | +3 | 6 | 238 |
| C X (앞차기 → 나래차기 (띄우기)) | 점프 → X 또는 C | +1 | 4 | 183 |
