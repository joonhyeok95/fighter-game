<callout icon="🥋" color="gray_bg">
**잡기와 던지기의 달인**\
잡기 범위가 넓고, 타격이 맞은 상대를 바로 잡을 수 있다. 반격 성공 시 던지기로 연결.
</callout>

## 개요

- 잡기 범위 +40%
- 콤보 중 Z+X로 잡기 캔슬
- 반격 → 관절 던지기
- 특수키: 업어치기 (가드불가)
- 대시 특수키: 태클 (슈퍼아머)

| 능력 | 등급 |
|---|---|
| 속도 | ■■■□□ |
| 리치 | ■■□□□ |
| 콤보 | ■■■□□ |
| 파워 | ■■■■□ |
| 잡기 | ■■■■■ |

<callout icon="📌" color="blue_bg">
대표 연계\
- 최대 피해 지상 연계: **C X Z+X** (정강이 차기 → 팔꿈치 치기 → 잡기 캔슬) — 3타 171
- 최대 피해 공중 연계: **X Z+X → 점프 → X 또는 C** — 3타 188
</callout>

## 4. 공중에 띄우는 공격 (던지기)

잡기 캔슬로 던져 올리는 연계 (업어치기 V는 등 뒤로 내리꽂는 기술이라 띄우지 않는다)

| 입력 | 연계 | 타수 | 피해 | 결과 |
|---|---|---|---|---|
| X Z+X | 장타 → 잡기 캔슬 | 2 | 125 | 던지기 |
| X X Z+X | 장타 → 팔꿈치 치기 → 잡기 캔슬 | 3 | 166 | 던지기 |
| C X Z+X | 정강이 차기 → 팔꿈치 치기 → 잡기 캔슬 | 3 | 171 | 던지기 |

## 5. 띄운 후 추가 연계

잡기로 던져 올린 직후 **점프(Space)로 던지기 동작을 캔슬**하고 공중에서 추격한다.

| 띄우기 연계 | 추가 입력 | 추가 타수 | 총 타수 | 총 피해 |
|---|---|---|---|---|
| X Z+X (장타 → 잡기 캔슬) | 점프 → X 또는 C | +1 | 3 | 188 |
