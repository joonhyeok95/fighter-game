## 5. 띄운 후 추가 연계

띄운 상대는 낮게 떠서 천천히 떨어진다. 띄우기가 맞으면 **X로 후딜레이를 끊고 서서 주먹을 넣고**, 연계 창이 닫힌 뒤 다시 X를 누르면 첫 주먹이 다시 나간다(**끊치**). 기본 루트는 **띄우기 → 끊치 2회 → 지상 콤보**. 점프(Space)로 쫓아가 공중에서 칠 수도 있다. 공중 추가타는 맞을수록 덜 뜨므로(저글 감쇠) 무한 연계는 되지 않는다.

| 띄우기 연계 | 추가 입력 | 추가 타수 | 총 타수 | 총 피해 |
|---|---|---|---|---|
| 대시 V (플라잉 니킥) | X → X(끊치) → X(끊치) → X → X | +5 | 6 | 250 |
| 대시 V (플라잉 니킥) | X → X → X | +3 | 4 | 209 |
| 대시 V (플라잉 니킥) | X → X → C | +3 | 4 | 196 |
| C X (로우킥 → 니킥 (띄우기)) | X → X(끊치) → X(끊치) → X → X | +5 | 7 | 252 |
| C X (로우킥 → 니킥 (띄우기)) | X → X → X | +3 | 5 | 216 |
| C X (로우킥 → 니킥 (띄우기)) | X → X → C | +3 | 5 | 204 |
| C X (로우킥 → 니킥 (띄우기)) | 점프 → X 또는 C | +1 | 3 | 150 |
